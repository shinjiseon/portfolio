# 포트폴리오 웹사이트 설계

## 배경 및 목표

studioheed.com의 레이아웃(가로 스크롤 작업물 그리드, 미니멀한 헤더)을 참고하여 개인 포트폴리오 웹사이트를 새로 제작한다. 이전에 다른 대화에서 만들었던 "Empty Studio" 시안(콜로소 강의용 가상 스튜디오, 워드프레스 기반)은 지난 디자인으로, 이번 작업과 무관하며 참고하지 않는다.

실제 프로젝트 콘텐츠(이름, 소개, 프로젝트 이미지/영상, 연락처)는 아직 준비되지 않았으므로, 이번 작업에서는 플레이스홀더 콘텐츠로 구조와 인터랙션을 완성하고 이후 실제 콘텐츠로 쉽게 교체 가능한 형태로 만든다.

## 참고 레이아웃 (studioheed.com 분석)

- 상단 헤더: 좌측에 이름/브랜드명 + 내비게이션(Work, Info), 우측에 이메일·SNS 연락처
- 헤더 아래 짧은 한 줄 소개 문구
- 화면 하단부에 프로젝트 썸네일이 가로로 나열되는 그리드 — 마우스 휠 또는 드래그로 옆으로 스크롤되며, 이미지 위/아래에 제목과 카테고리 텍스트가 붙는다
- 썸네일 클릭 시 개별 프로젝트 상세 페이지로 이동

## 확정된 방향

- **비주얼 톤**: 블랙 배경(#0d0d0d 계열) + 화이트 텍스트. 여백을 넉넉히 두어 이미지/GIF가 도드라지게 한다.
- **타이포그래피**: 특정 브랜드 폰트 지정 없이 깔끔한 산세리프(시스템 폰트 또는 웹폰트 하나)를 사용한다.
- **기술 스택**: 순수 HTML/CSS/JS 정적 사이트. 프레임워크·서버·빌드 도구 없이 파일만으로 완성하여, 정적 호스팅(Vercel/Netlify/GitHub Pages 등)에 바로 배포 가능하게 한다.
- **콘텐츠 관리 방식**: 프로젝트 데이터(이미지 경로, 제목, 카테고리, 설명, 상세 이미지/영상 목록)를 한 곳(JS 데이터 파일 또는 JSON)에 모아두어, 실제 콘텐츠가 준비되면 해당 파일만 교체/추가하면 되도록 구성한다.
- **미디어**: 이미지뿐 아니라 GIF, 짧은 영상(mp4)도 프로젝트 상세 페이지에 자유롭게 넣을 수 있어야 한다.

## 페이지 구성

### 1. Home (`index.html`)
- 헤더: 이름/로고, 내비게이션(Work / Info), 우측 연락처(이메일, Instagram 등)
- 짧은 소개 문구 한 줄
- 가로 스크롤 프로젝트 그리드: 플레이스홀더 프로젝트 4~6개, 각각 썸네일 이미지 + 제목 + 카테고리
- 그리드는 마우스 휠 세로 스크롤을 가로 스크롤로 변환 + 드래그 스크롤 지원
- 썸네일 클릭 → 해당 프로젝트 상세 페이지로 이동

### 2. 프로젝트 상세 페이지 (`project.html?id=...` 또는 정적 파일 `projects/{slug}.html`)
- 상단: 큰 히어로 이미지/영상 + 프로젝트 제목, 간단 설명, 메타 정보(역할, 연도 등)
- 본문: 추가 이미지/GIF/영상들을 세로로 나열 (studioheed의 상세 페이지처럼 캡션 포함 가능)
- 하단: 다른 프로젝트로 이동하는 네비게이션, 공통 푸터

### 3. Info 페이지 (`info.html`)
- 자기소개, 경력/스킬 요약
- 연락처 및 SNS 링크
- (선택) 크레딧/저작권 문구

### 공통 요소
- 헤더/푸터는 모든 페이지에서 동일한 구조 (JS로 공통 삽입하거나 각 페이지에 동일 마크업 복사)
- 반응형: 데스크톱 우선이되, 모바일에서도 레이아웃이 깨지지 않도록 기본 반응형 처리

## 플레이스홀더 콘텐츠

- 프로젝트 4~6개: Unsplash 등에서 가져온 무료 이미지 또는 단색/그라디언트 블록으로 대체
- 텍스트: "Project One", "Lorem ipsum..." 등 명확히 플레이스홀더임을 알 수 있는 텍스트 사용
- 실제 콘텐츠 교체 방법을 README에 간단히 안내

## 테스트/검증 방법

- 브라우저(Claude Browser 프리뷰)로 Home, 프로젝트 상세, Info 페이지를 직접 열어 가로 스크롤 동작, 페이지 이동, 반응형 레이아웃을 확인한다.
- 별도 자동화 테스트는 두지 않는다 (정적 사이트 특성상 시각적 확인이 핵심).

## 범위 밖

- 워드프레스/CMS 연동
- 실제 프로젝트 콘텐츠 제작 (텍스트/이미지 자체는 사용자가 추후 준비)
- 다국어 지원
- 배포 자동화(CI/CD) 설정
